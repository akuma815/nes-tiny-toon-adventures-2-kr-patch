# 작업218 — 오프닝·크레딧 IRQ CPU 검증과 재개 인계

오프닝9개와 진행 크레딧2개의852출력 호출에 원래 IRQ 벡터FA5B를 주입했다. 모든 본문 커서에서 mode0의 종료/ack 콜백을, 첫 호출과 출력 없는 개행·종료 호출에서는5종 콜백을 검사했다. 각 호출의 PC 첫/마지막 방문 경계가 대상이다. 첫 크레딧 A448→A44B 직접출력에서도 mode0만 검사했다. 총149,824주입에서 CPU 레지스터·PRG·큐·본문 상태·C6 래치 복귀를 통과했고 최저 SP240이었다. 이 기준의192바이트 큐 뒤 범위 여유는48바이트다. [218 CPU 보고](../qa/reports/irq218_opening_credits.json).

기준 출력 결과는 오프닝9와 크레딧2의 NT 좌표/타일에 정확히 일치했다. 첫 크레딧 기준 출력756셀·렌더중지·2000 복원도211의native경로와 같았다. 이 기준 출력은 IRQ를 PPU 모델에 섞어 실행한 결과가 아니다. 첫 크레딧의 mode0 콜백은 IRQ acknowledge/disable만 수행하므로 RAM·레지스터·PRG 보존만 검사했고, PPU/CHR를 바꾸는 다른 콜백은 직접출력 도중 주입하지 않았다. 실제 초기 크레딧의 IRQ enable/context와 발생시각은 아직 증명하지 않았다.
